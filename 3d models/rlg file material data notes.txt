mario.rlg

Material data: section identifier 0x8016, usually found at the beginning of files.

This section seems to be split in 12 chunks all of the same size (0x68 bytes each).
Each of the 12 chunks is associated to one of the 12 meshes.

In the mesh data section you can find the offset of a meshe's material

I'm not sure why, but in mario.rlg every mesh has material_hash_id 449715457
which I guess means the material is the same. 
These look like 12 different materials to me though.
Maybe the material_hash_id value identifies the file (mario.rlt)




The textures are actually stored in an .rlt file. This section just contains references to that file

Use PyGLT to extract textures from rlt files. https://github.com/MCMANIRX/pyGLT
How to use:
Go to the directory of the script
Run this command:  python pyGLT.py <rlt file path> dec
If you get errors it could be that you need to install some python modules which pyGLT relies on (cv2, numpy)
(alternatively, you can use GLTool: https://github.com/MCMANIRX/GLTool )


If everything went correctly you'll find a folder containing all the textures. 
Each texture will have the hash_id in its name. Those hashes are used by the rlg file to reference the textures

The chunks of the material section are structured as follows:
0x00-0x03: hash_id of "main" texture (like mario's eye, mario's head, mario's rest, that stuff)
0x04-0x07: FF FF 00 00
0x08-0x0B: hash_id for some other texture, I think these are reflection textures? (*)
0x0C-0x0F: FF FF 00 00
0x10-0x13: hash_id for grayscale texture thing (again, idk what this stuff's called) mario eye and head have their own
0x14-0x17: FF FF 00 00
0x18-0x1B: hash_id for red/gray texture thing
0x1C-0x1F: FF FF 00 00
0x20-0x23: 24 B5 5F B9  hash_id of mud texture.
0x24-0x27: FF FF 00 00
0x28-0x2B: 5E 34 1F 17  hash_id of ice texture.
0x2C-0x2F: FF FF 00 00
0x30-0x37: 00 00 00 00 00 00 00 00
0x38-0x47: 3F 80 00 00 repeat 4 times. These are float 1
0x48-0x4B: either 00 00 00 01 (meshes 1,2,3,8) or 00 00 00 00 (all other meshes)  I have no idea what this is for
0x4C-0x53: 00 00 00 00 00 00 00 00
0x54-0x57: FF FF FF FF
0x58-0x5B: 00 00 00 01
0x5C-0x68: 00 repeat 12 times

(*) One of these is something that seems like it's used for reflections, the other is a small black square with a white dot in the middle.
This might be common knowledge stuff for people who are experienced at 3d modelling, but I have no idea what these are
