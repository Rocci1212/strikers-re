# Memory addresses (Mario Strikers Charged)
This folder contains notes about MSC memory addresses.  
There are 5 regional variants of the game (PAL revision 1/2, NTSC-U/J/K).  
Important: PAL revision 2 is NOT the same as revision 1.  
All the addresses listed in this documentation are relative to PAL revision 1.  
  
The directory structure of this documentation is organized in subfolders based on the topic of each page.  
  
Some data might be inexact. In particular, addresses listed in this documentation might not be statically allocated even though they were noted as such.
